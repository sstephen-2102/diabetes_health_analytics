was checked to resolve, and journal metadata was taken from the DOI registry.

Paste the list into the report in alphabetical order (already sorted), with a
hanging indent. In Markdown the italics mark the parts APA italicizes: book and
data-set titles, journal names and volume numbers.

## Software versions

Versions behind the committed EDA and regression outputs are recorded in
`outputs/eda_manifest.json` and `outputs/regression_manifest.json`. The
environment used for the modeling exports and app has Python 3.14.6,
scikit-learn 1.9.1, statsmodels 0.15.0, pandas 3.0.6, NumPy 2.5.3, SciPy 1.18.1,
Matplotlib 3.11.2, Streamlit 1.64.0 and Plotly 7.1.0. CI runs Python 3.12 with
unpinned `requirements.txt`, so state versions in the report as "used to
produce the reported results".
